# Making an asset pack

Packs restyle Wallet-landia: heroes and mounts, townsfolk, caravans, treasure icons, buildings (2D and 3D), scenery, and the names of places. A pack is **data only**: a `pack.json` plus images and glTF models. It can never run code.

Players install packs in **🎨 Looks → Import pack folder…** (pick the folder that contains `pack.json`) and choose per slot which pack draws it. Everything not chosen uses the built-in "Hearth & Harvest" art. The sample pack lives in [`public/packs/ember-frost/`](../public/packs/ember-frost/) and is generated by [`scripts/sample-pack/generate.py`](../scripts/sample-pack/generate.py).

## `pack.json`

```jsonc
{
  "format": "wallet-landia-pack/2", // "/1" still works for slot-only packs
  "id": "ember-frost",            // 2–40 chars: a-z 0-9 -   ("default" is reserved)
  "name": "Ember & Frost",
  "author": "You",
  "version": "0.1.0",
  "license": "CC0-1.0",            // optional, shown to players
  "description": "…",             // optional, ≤ 300 chars
  "slots": {
    "npc.raven":      { "sprite": { "src": "owl.svg", "ax": 10, "ay": 20, "frames": 2 } },
    "building.bank":  {
      "top":   { "src": "vault-top.svg", "ax": 0,  "ay": 64, "sign": { "x": 19, "y": 9, "w": 11, "h": 11 } },
      "iso":   { "src": "vault-iso.svg", "ax": 48, "ay": 52 },
      "model": { "src": "vault.gltf" }
    },
    "word.building.bank": { "word": "Frost Vault" }
  }
}
```

## Forms

| Form | Used for | Notes |
|---|---|---|
| `sprite` | heroes, townsfolk, caravans, items, 2D scenery | Also the 3D billboard for people. |
| `top` | building in the top-down view | Anchor at the footprint's **bottom-left**. |
| `iso` | building in the isometric view | Anchor at the footprint's **top corner**. A 3×3 footprint is a 96×48 diamond. |
| `model` | building or scenery in 3D | glTF/GLB. Units are tiles; origin at the footprint centre on the ground; +z faces the street. Buildings are scaled down to fit the footprint. |
| `word` | a name in the lexicon | ≤ 40 characters. |

### Sprites
- **Scale: 16 art pixels = 1 tile**, in every view. Draw at that size; the game scales up with crisp pixels.
- `ax, ay` is the point that stands on the ground (a character's feet).
- `frames`: a horizontal strip of equal-width animation frames, e.g. a 2-frame walk cycle.
- `sign` (buildings): where the protocol's logo is drawn, in sprite pixels.
- PNG, WebP, GIF, JPEG or SVG. SVG renders as an image, so its scripts never run.

### Models
- `.glb`, or `.gltf` whose buffers and textures are embedded or sit in the same folder.
- Normals may be omitted (flat normals are computed); keep counts low (hundreds of triangles), since scenery is cloned many times.

## Slots

The full list is in [`src/assets/catalog.ts`](../src/assets/catalog.ts). Families:

| Family | Keys |
|---|---|
| Heroes | `hero.t0` … `hero.t6` (tier = value, decides the mount), optionally per class: `hero.t3.merchant`, `hero.t5.monk`, … (`merchant monk paladin bard ranger adventurer sleeper`). The more specific key wins. |
| Townsfolk | `npc.raven`, `npc.herald`, `npc.bailiff`, `npc.villager` |
| Caravans | `caravan.t1` … `caravan.t6` |
| Treasure | `item.native stable wrapped governance meme lst receipt debt token nft spam pouch` |
| Scenery | `prop.tree pine bush rock` (sprite for 2D, model for 3D) |
| Buildings | `building.bazaar broker bank temple barracks alchemist auction harbour council names packing forge herald tent`, `building.tower guildhall gate`, `building.home.t0` … `t6` |
| Names | `word.building.<kind>`, `word.district.temple alchemy civic wilds counting square market guild harbour` |

## Rules the importer enforces
- Paths must be relative and stay inside the pack: no `..`, no absolute paths, no `http:`, `data:` or other schemes.
- Allowed files: images (`png webp gif jpg svg`) and models (`gltf glb bin`). Everything else is ignored.
- At most 300 files and 25 MB per pack.
- Unknown slots, or forms a slot doesn't take, are dropped with a reason shown at import.
- Every file `pack.json` refers to must be present.

Imported packs stay in your browser (IndexedDB). Bundled packs are listed in `public/packs/index.json`.

## Theme bundles (format 2)

A pack can also carry a whole look in a `theme` block: sky, materials, ground, buildings, surroundings, characters and mounts. Players pick one in **🎨 Looks → World theme** to redraw the 3D town; the look sandbox lists the same themes. Bundled themes come from `public/themes/index.json`; imported packs that have a theme block appear too.

The reference bundle is [`public/themes/medieval/pack.json`](../public/themes/medieval/pack.json). [`highland`](../public/themes/highland/pack.json) is a variant with no files of its own; [`modern`](../public/themes/modern/pack.json) and [`scifi`](../public/themes/scifi/pack.json) extend medieval with their own textures, building style, props and vehicle mounts. The validator is [`src/assets/theme.ts`](../src/assets/theme.ts).

```jsonc
"theme": {
  "extends": "medieval",          // optional: start from another theme, override parts
  "sky": "overcast",              // day | sunset | night | overcast (the daytime sky)
  "notes": ["What is still missing"],
  "materials": {                   // by role, see below
    "stone":   { "color": "materials/stone/color.webp", "normal": "…", "roughness": "…", "size": 1.25 },
    "plaster": { "use": "stone", "tint": "#d8d4cc" },   // another role's textures, retinted
    "thatch":  { "tint": "#a89880" },                    // with extends: retint the parent's
    "iron":    { "tint": "#3a3a40", "metalness": 0.7, "roughnessValue": 0.5 }
  },
  "ground": { "grass": "grass", "road": "cobbles", "plaza": "cobbles", "path": "dirt" },
  "buildings": { "style": "medieval", "washes": ["#f4ead6"], "brandRoofs": 1 },
  "surroundings": { "style": "medieval", "relief": 1, "woods": 1, "trees": { "oak": 0.57, "birch": 0.18, "fir": 0.25 },
                    "grass": { "hue": 0.24, "sat": 0.45, "light": 0.17 }, "flowers": 700, "lamps": "lantern" },
  "characters": { … }
}
```

### Materials
Roles: `plaster stone stoneDark timber planks roofTiles roofSlate thatch cobbles asphalt grass dirt cloth bark rock forestFloor glass fire iron gold`. The building grammar, terrain and props ask for surfaces by role, so a theme restyles everything by giving each role a material.
- `color`, `normal` (OpenGL convention, green up), `roughness`: image files. Any can be left out.
- `size`: metres covered by one repeat of the textures. Geometry carries UVs in metres, so a brick is the same size everywhere.
- `tint` multiplies the colour (and is the whole colour of an untextured role). `use` takes another role's textures and size.
- A role the theme leaves out falls back to a plain colour, so nothing goes missing.

### Buildings and surroundings
`style` picks the code that builds them: `"medieval"`, `"modern"` or `"scifi"`. Each style reads the roles its own way:

| Role | medieval | modern | scifi |
|---|---|---|---|
| `stone` | masonry | facing brick | hull panels |
| `plaster` | lime render | render | white composite |
| `stoneDark` | plinths, quoins | concrete | dark plating |
| `timber` | beams, frames | steel frames | metal frames |
| `planks` | doors, cladding | timber cladding | deck plate |
| `roofTiles` / `roofSlate` | tiles / slate | pitched roofs / flat roofs and sheds | roof panels |
| `fire` | fires | chimney glow | glowing seams (tint it) |

The surroundings style picks the props (rustic: barrels, woodpiles, a well, a paddock; urban: bins, benches, bollards, a fountain, a park; colony: canisters, a water tank, a solar farm, a pipeline) and the default lamps. The other fields tune it:
- `washes`: plaster colours picked per building. `brandRoofs`: 0..1, how strongly a protocol's brand colour tints its roof.
- `relief`: hill height (0 = flat). `woods`: how much land is wooded. `trees`: the species mix (firs also take over higher up). `grass`: blade colour (HSL, 0..1). `flowers`: how many clumps. `lamps`: `lantern`, `post` or `beacon`.

### Characters
Every part shares one skeleton, so no retargeting is needed. The only rig so far is `"ue5-universal"`: Unreal-5 bone names (`pelvis`, `thigh_l`, `Head`…) and bind pose, as in the Quaternius Universal kits.

```jsonc
"characters": {
  "skeleton": "ue5-universal",
  "animations": "anim/ual.glb",                       // one glTF with all clips
  "clips": { "idle": "Idle_Loop", "walk": "Walk_Loop", "run": "Jog_Fwd_Loop", "sit": "Sitting_Idle_Loop" },
  "speeds": { "walk": 1.25, "run": 3.0 },              // m/s at normal playback, so feet don't slide
  "bodies": { "male": "base/M.glb", "female": "base/F.glb" },
  "bodyParts": "head",                                 // keep only the head (outfits cover the body) or "full"
  "outfits": { "default": {"male": "…", "female": "…"}, "villager": {…}, "merchant": {…} },  // per class optional
  "hair": { "male": ["hair/a.glb"], "female": ["hair/b.glb"] },
  "eyebrows": { "male": "…", "female": "…" },
  "mounts": {                                          // by value tier, t2 … t6
    "t3": { "model": "animals/Horse.fbx", "height": 2.0, "tint": "#4a4048",
            "clips": { "idle": ["Idle"], "walk": ["Walk"], "run": ["Gallop", "Run"] },
            "speeds": { "walk": 1.6, "run": 5 },
            "seat": { "from": "Torso", "to": "Shoulders", "t": 0.33 },  // where the rider sits, between two bones
            "wings": { "color": "#f2ead8", "span": 0.48 } }              // placeholder wings
  }
}
```
- Instead of a `model`, a mount can be a `vehicle` built in code: `bicycle scooter motorbike helicopter jet hoverboard hoverbike hoverbikeHeavy skiff starship`. Vehicles have their own size and seat; `tint` paints them (default: the hero's crest colour); `pose` (`straddle` or `sit`) overrides how the rider sits.
- Mount models may be `.glb`, `.gltf` or `.fbx` (many creature kits ship only FBX). Clip names match whole names, also after a `|` (`"Idle"` matches `Armature|Idle`). The first listed clip that exists wins.
- The rider is seated with the `sit` clip, the legs turned into a straddle, and the pelvis put on the mount's back between the `seat` bones.

### Inheritance
With `extends`, every block overrides field by field: a material entry with just a `tint` keeps the parent's textures. `characters` may give only some fields (say, just `mounts`): mounts override per tier, `outfits` replaces the whole wardrobe, the rest field by field. A complete `characters` block replaces the parent's. Files are resolved against the pack that names them, so a variant reuses its parent's files without copying them.

### Limits
The same rules as slots: relative paths inside the pack only, images and models only, at most 300 files and 25 MB per imported pack. Unknown fields, roles and tiers are dropped with a reason, never guessed.
